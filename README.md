# Kashyap_Nirmal.github.io

The deployed application can be found at: [kashyap-nirmal.github.io](https://kashyap-nirmal.github.io)

This repository hosts my personal website and work portfolio, deployed with [GitHub Pages](https://pages.github.com/).

The homepage includes canonical URL, social sharing metadata, and Schema.org person/website data. `robots.txt` allows crawler access and points to `sitemap.xml`.

Search ranking is determined by search engines and cannot be guaranteed. After publishing, verify the site in [Google Search Console](https://search.google.com/search-console/about) and submit `https://kashyap-nirmal.github.io/sitemap.xml` for indexing.
